# Remaining submission and release checks

## Prepared locally
- Offline analysis core, exact dependency versions, checksum inventory and verification commands.
- Retained original analysis files; no new model outputs or numerical manuscript claims created.

## Must be completed
- Create/select the paper repository; verify authenticated read/write access and successful remote checkout.
- Run the documented checks from that remote checkout; record release tag and commit SHA.
- Confirm benchmark-derived redistribution rights and author-selected software/data licenses.
- Integrate and test the later stimulus-defect sensitivity code and numbered Files S1–S15, or explicitly link these as separate journal supplements. This core alone does not reproduce every final manuscript claim.
- Set reviewer access appropriate to the journal's review model. A private repository URL alone is insufficient for editors/reviewers without access; check anonymity requirements before exposing author identity.
- Replace manuscript repository/access placeholders only after access works. Archive a fixed release if a durable identifier is required.
- Complete author names, affiliations, corresponding author, CRediT, funding, competing interests, ethics determination and author approval.
- Ensure current manuscript, appendix, figures, references and supplements are the same approved version. This preparation does not certify the latest manuscript or current journal formatting rules.
- Verify current Artificial Intelligence in Medicine author instructions in the submission portal, including file types, abstract/keywords, declarations, highlights and review anonymity.

No additional experiment is made a prerequisite by this checklist. Limitations must remain explicit.
