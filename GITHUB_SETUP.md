# Repository access

Canonical repository: https://github.com/Myssar/arabic-medical-qa-reproducibility (public, default branch `main`).

```bash
git clone https://github.com/Myssar/arabic-medical-qa-reproducibility.git
```

Do not commit passwords, tokens, MedAraBench question text, or the review web app's generated `dataA.gs`, `dataB.gs` and `partB_key.csv` files (they are listed in `.gitignore`).
