# Repository access and checkout

Canonical repository: https://github.com/Myssar/arabic-medical-qa-reproducibility

The repository is private. On 23 September 2026, the connected Myssar account was verified as repository administrator with push access. The default branch is `main`.

For a local checkout, use:

```bash
git clone https://github.com/Myssar/arabic-medical-qa-reproducibility.git
cd arabic-medical-qa-reproducibility
```

GitHub authentication is handled by GitHub on your own machine. Do not place passwords or tokens in this repository. The ChatGPT GitHub connection currently has repository access; that does not automatically grant access to journal reviewers. Grant reviewer access through the journal-appropriate mechanism before claiming reviewer availability.
